# Awesome AI Resources

这里收录适合 AI 应用工程师持续学习的高质量资源。原则是少而精，优先选择官方文档、经典教程和真实工程案例。

## 学习顺序建议

新手不要一开始就打开几十个链接。建议按这个顺序：

1. 先读模型平台官方文档，知道 API 怎么用。
2. 再读 RAG 和 Agent 框架文档，知道常见架构。
3. 做项目时查向量数据库、部署和评测工具。
4. 遇到具体问题再看论文和深度文章。

## 推荐筛选标准

加入资源前请确认：

- 是否仍在维护
- 是否有清晰示例
- 是否适合中文开发者学习
- 是否能帮助完成真实项目
- 是否避免标题党和低质量搬运

## 不建议新手一开始深挖的内容

- 大模型预训练细节
- 分布式训练优化
- CUDA 底层性能调优
- 复杂多 Agent 理论
- 追逐所有新框架

这些内容不是不重要，而是对“先做出 AI 应用”来说优先级没那么高。
