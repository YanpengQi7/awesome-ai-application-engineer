# Tool Calling

这个示例展示工具调用的核心思想：模型不应该凭空回答所有问题，而是在需要外部信息时调用工具。

```text
用户问题 -> 判断需要哪个工具 -> 生成工具参数 -> 执行工具 -> 用工具结果回答
```

## 运行方式

```bash
cd examples/tool-calling
python tool_calling_demo.py
```

## 你应该观察什么

- 工具名称是否清晰
- 工具参数是否结构化
- 工具返回值是否简洁
- 最终回答是否基于工具结果
