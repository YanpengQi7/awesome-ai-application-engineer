# Examples

这里放最小代码示例。目标不是做完整生产项目，而是让新手快速理解核心链路。

## 示例列表

| 示例 | 说明 |
| --- | --- |
| [minimal-rag](minimal-rag/README.md) | 用最少代码理解 RAG 的检索增强生成流程 |
| [tool-calling](tool-calling/README.md) | 理解模型如何选择工具并使用工具结果 |
| [minimal-mcp-server](minimal-mcp-server/README.md) | 理解 MCP Server 如何暴露工具给 AI 客户端 |

## 学习建议

1. 先读 README，不急着运行。
2. 画出输入、处理、输出的数据流。
3. 运行后故意改坏一个地方，观察错误。
4. 把示例改成你自己的小项目。
