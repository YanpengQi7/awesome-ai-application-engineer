Prompt Template

你是一个{角色}。

任务：
{明确说明要完成的任务}

背景：
{提供必要上下文}

输入：
{用户输入或系统提供的信息}

约束：
- {约束 1}
- {约束 2}
- 不要编造未提供的信息

输出格式：
{明确 JSON、Markdown、表格或自然语言格式}

失败处理：
如果信息不足，请说明缺少什么信息，不要猜测。

使用建议

  • 先写清楚任务，再补角色
  • 输出格式越关键，越应该用 schema
  • 对高风险任务加入拒答规则
  • 每次修改 prompt 后保留版本
  • 用真实 bad case 测试 prompt
